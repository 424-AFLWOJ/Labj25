# Лабораторная работа № 3 — интерфейсы и полиморфизм

**Профиль:** программная инженерия.

## Подготовительная часть
Создан интерфейс `DiscountPolicy` и две реализации:
- `NoDiscount` — возвращает исходную цену;
- `PercentDiscount` — применяет процентную скидку от 0 до 100 включительно.

`PriceCalculator` получает `DiscountPolicy` через конструктор и не создаёт конкретную реализацию внутри себя.

## Обязательная часть
Создан интерфейс `PriorityPolicy` и две реализации:
- `EffortPriorityPolicy` — отдаёт больший приоритет задаче с меньшей оценкой трудоёмкости;
- `StatusPriorityPolicy` — использует порядок `IN_PROGRESS > TODO > DONE`.

`TaskPrioritizer` получает `PriorityPolicy` через конструктор и выбирает задачу с более высоким приоритетом. При равном приоритете возвращается первая задача.

Модель `ProjectTask` локальная для модуля `lab03`, чтобы лабораторная оставалась независимой от `lab02`.

## Тестирование
Проверяются обе реализации скидки, ограничения процента и цены, обе стратегии приоритизации, замена стратегии без изменения клиента, неизменность моделей при обработке и обработка null.

