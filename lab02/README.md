# Лабораторная работа № 2 — классы и инкапсуляция

**Профиль:** программная инженерия.

## Подготовительная часть
Реализован `BankAccount`:
- отрицательный начальный баланс запрещён;
- `deposit` и `withdraw` принимают только положительные суммы;
- снятие сверх остатка запрещено;
- переполнение баланса при пополнении запрещено;
- баланс доступен только через getter, setter отсутствует.

## Обязательная часть
Реализован `ProjectTask` с полями:
- `id`;
- `title`;
- `status`;
- `estimatedHours`.

Инварианты:
- `id` и `title` не могут быть null, пустыми или состоять из пробелов;
- `status` не может быть null;
- `estimatedHours` должен быть больше нуля;
- все поля private;
- `id` и `title` final;
- статус меняется через `changeStatus`;
- оценка трудоёмкости увеличивается только на положительное значение;
- переполнение int запрещено.

## Тестирование
Проверяются корректное создание, ограничения конструктора, изменение статуса, увеличение оценки, ошибки входных значений и переполнение.
