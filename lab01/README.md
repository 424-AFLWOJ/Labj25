# Лабораторная работа № 1 — методы, управление выполнением и тесты

**Профиль:** программная инженерия.

## Выполнено

### Подготовительная часть
- сохранён исходный метод `isEven`;
- добавлены тесты для отрицательного чётного числа, отрицательного нечётного числа и нуля.

### Обязательная часть
- `isPrime(int)` — проверка простого числа, включая значения меньше 2, составные числа и квадраты простых чисел;
- `isPalindrome(String)` — проверка палиндрома с учётом регистра и пробелов; для `null` выбрасывается `IllegalArgumentException`;
- `average(int[])` — вычисление среднего значения с дробным результатом без изменения массива; для `null` и пустого массива выбрасывается `IllegalArgumentException`.

### Дополнительная часть
- `min(int[])` и `max(int[])`;
- тесты для обычного массива, массива из одного элемента и ошибочных входных данных.

## Особенность реализации

В `isPrime` квадрат делителя вычисляется как `long`, чтобы избежать переполнения `int` на больших входных значениях.
