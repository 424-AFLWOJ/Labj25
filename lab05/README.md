# Лабораторная работа № 5 — файлы, исключения и валидация

**Профиль:** программная инженерия.

## Подготовительная часть
Во временном каталоге `@TempDir` создаётся UTF-8-файл со строками `10`, `bad`, `20`. Проверяются чтение, преобразование циклом и исключение `NumberFormatException`.

## Обязательная часть
Созданы `ProjectTask`, `TaskStatus`, `ValidationError`, `LoadResult`, `DataLoadingException` и `TaskFileLoader`.

`TaskFileLoader.load(Path)` читает UTF-8-файл, отдельно проверяет заголовок и обрабатывает строки обычным циклом. Корректные задачи и ошибки возвращаются раздельно. Ошибка файла сохраняет исходный `IOException` в `cause`. Loader ничего не печатает.

Принятые правила: заголовок должен точно совпадать с `id;title;category;estimatedHours;status`; пустые строки пропускаются, номера строк считаются по исходному файлу, начиная с 1. Текст обрезается по краям и не может быть пустым. Трудоёмкость — положительное целое `int`. Статусы: `TODO`, `READY`, `IN_PROGRESS`, `DONE` (регистр важен). При неверном заголовке возвращается ошибка `header`, строки не разбираются. Разделитель внутри поля и CSV-кавычки не поддерживаются — это дополнительная часть задания.

## Тестирование
Проверяются корректный файл, кириллица, пустые поля (в том числе последнее), неправильное и слишком большое число, неположительная трудоёмкость, неизвестный статус, лишние/недостающие столбцы, смешанный файл, заголовок, пустой файл и отсутствующий файл с сохранением причины.
