# Лабораторная работа № 6 — коллекции и дженерики

**Профиль:** программная инженерия.

## Подготовительная часть
Создан `Box<T>` с конструктором и методами `get`, `set`. В тестах используются `Box<String>` и `Box<Integer>`. Некомпилируемая передача числа в строковый контейнер показана комментарием.

## Обязательная часть
Создан `Stack<T>` на основе `ArrayList<T>`: `push`, `pop`, `peek`, `size`, `isEmpty`. Значение `null` запрещено; пустые `pop` и `peek` выбрасывают `NoSuchElementException`.

`DataAnalytics` считает задачи по статусам через `EnumMap`, собирает категории через `LinkedHashSet` и сортирует копию списка по трудоёмкости, затем по идентификатору через `Comparator`.

`ArrayList` удобен для добавления/удаления в конце. `EnumMap` подходит для ключа-enum и обходит ключи в порядке объявления статусов; отсутствующие статусы не включаются. `LinkedHashSet` удаляет повторы и сохраняет порядок первого появления. Сортировка использует `Integer.compare`, а не вычитание. Категории сравниваются с учётом регистра. Исходный список не меняется.

## Тестирование
Проверяются оба типа Box, стек для Integer и String, LIFO, отсутствие удаления при peek, размер, пустой стек, запрет null, группировка, порядок уникальных категорий, сортировка равных ключей и неизменность входа.
