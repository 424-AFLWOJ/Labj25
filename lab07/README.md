# Лабораторная работа № 7 — лямбды и Stream API

**Профиль:** программная инженерия.

## Подготовительная часть
`WordProcessor` получает из изменяемого списка `java`, пустой строки, `git`, `maven`, `api` новый список `API`, `GIT`, `JAVA`, `MAVEN`. Тест сравнивает исходный список с сохранённой копией.

## Обязательная часть
`DataAnalytics` реализует фильтр по статусу, нормализованные категории, подсчёт по категориям, максимум трудоёмкости через `Optional` и сортировку по трудоёмкости и идентификатору. Метод `titlesByStatus` дополнительно возвращает отсортированные названия задач заданного статуса.

Категории приводятся к нижнему регистру с `Locale.ROOT`; повторы в списке категорий сохраняются. Группировка использует ту же нормализацию и `TreeMap` для алфавитного порядка ключей. При равной максимальной трудоёмкости выбирается задача с лексикографически большим id. Сортировка задач — по возрастанию обоих ключей; фильтр сохраняет порядок входа.

Используются последовательные `stream`, `filter`, `map`, `sorted`, `groupingBy`, `counting`, `max`, `toList`. В аналитике нет циклов, внешней мутации и `parallelStream`. Модель локальна для `lab07`.

## Тестирование
Проверяются пустой список, один элемент, несколько групп и статусов, нормализация, порядок ключей и результатов, равная трудоёмкость, пустой Optional, максимум и неизменность исходного изменяемого списка.
